# Media

This folder contains visualization artifacts generated from the recovered Revision 64 dimensions.

- `rev64_real_life_motion.gif` shows a looping motion preview of the moving six-coil bobbin over the nominal ±20 mm stroke.
- `rev64_animation_preview.png` is a still frame from the same animation.

These renders are illustrative. They show the recovered electromagnetic and bobbin geometry, while the guide, carriage, end retention, wiring exit and external mounting design are still open engineering work.
